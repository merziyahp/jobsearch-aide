Connect the trackers.

  1. Upload the workbook.

    In Google Drive, upload the downloaded file and choose Open with Google Sheets. You can keep the two trackers separate or copy both tabs into one spreadsheet.

  2. Open extension settings.

    Click the JobSearch Aide icon, open Settings, and sign in with the Google account that owns the sheet.

  3. Paste the sheet URL.

    Paste the full Google Sheets URL into Job Applications or Outreach Tracker, choose the matching tab, then save settings.

  4. Test one record.

    Save a job listing or a LinkedIn contact and confirm that a new row appears beneath the examples.

Keep the first row in place.

The current extension writes by column position. Do not reorder, insert, or remove columns A through N. You can rename the spreadsheet file and tab, add formatting, and delete the example data rows.

Check these first.

If the tab list does not appear, confirm that the signed-in Google account can edit the sheet, then paste the full Sheets URL again.

The extension does not write directly to a local `.xlsx` file. The file must be opened as a Google Sheet.

For networking, the LinkedIn URL is the main duplicate key. If there is no URL, the extension uses contact name plus company.
